This site brings together two portfolio prototypes and the existing `sharad.fr`
project homepage. The final direction keeps the wider project-card system and
floating navigation from the newer prototype, while retaining the quieter,
reading-first character of the earlier version.

The site is intentionally static: Astro generates the pages, GitHub Actions
assembles them with BasketMap, and GitHub Pages publishes the result to the
custom domain.

The public version only includes work that can be described honestly. Draft
essays, example employers, fictional projects, and stock biography text were
removed rather than presented as finished personal history.
